A URL shortener built with **ASP.NET Core**, created as a hands-on learning project to explore backend development, system design, and DevOps practices.

This repository documents the journey of designing, building, testing, and evolving a production-inspired service while learning the ASP.NET Core ecosystem from the ground up.

> [!NOTE]
> Whether you're learning ASP.NET Core, interested in backend architecture, or curious about how URL shorteners work, this repository aims to provide both a practical implementation and an educational resource.

## :rocket: Built With

- C# (.NET 9.0)
- ASP.NET Core
